# Internship Portal | Certified Industry Internship Platform

A modern, high-performance web platform for student internship programs, credential issuance, and verification.

## 🚀 Tech Stack
- **Frontend Framework**: React 19 + TypeScript + Vite
- **Styling**: Tailwind CSS v4 + Glassmorphism + Custom Fonts
- **Icons**: Lucide React
- **Payments**: Razorpay Checkout SDK
- **Backend & Database**: Firebase Firestore & Auth integration ready
- **Animations**: CSS transitions & smooth interactive state flows

## 🛠 Features
- **Curated Internship Tracks**: Full-Stack, Generative AI, Cloud & DevOps, Cyber Security, Data Science, Mobile Dev.
- **Dynamic Category & Search Filters**: Instant track discovery with live skill tags and duration selector.
- **Interactive Multi-Step Application**: Candidate profile, track configuration, and instant enrollment.
- **Razorpay Checkout Integration**: Secure payments for program kits & verified credentials.
- **Central Certificate & Offer Letter Verifier**: Real-time validation of completion credentials with sample demo testing (`INT-2026-9842`).
- **Campus MoU & Partnership Section**: Academic integration for colleges, universities, and corporate hiring networks.

## 📦 Getting Started
1. Run development server:
   ```bash
   npm run dev
   ```
2. Build for production:
   ```bash
   npm run build
   ```

## 🔑 Environment Variables (.env)
Update `.env` with your Firebase and Razorpay credentials:
```env
VITE_RAZORPAY_KEY_ID="rzp_test_..."
RAZORPAY_KEY_SECRET="..."

VITE_FIREBASE_API_KEY="..."
VITE_FIREBASE_AUTH_DOMAIN="..."
VITE_FIREBASE_PROJECT_ID="..."
VITE_FIREBASE_STORAGE_BUCKET="..."
VITE_FIREBASE_MESSAGING_SENDER_ID="..."
VITE_FIREBASE_APP_ID="..."
```
